# java-kanban

**Веб-сервис для отслеживания задач.**  
Repository for homework project.

## 🎯 Цель проекта
- Освоение основ Java Core (ООП, потоки ввода-вывода, работа с файлами)
- Применение принципов проектирования SOLID
- Практика создания HTTP-сервера на чистой Java
- Написание модульных тестов с использованием JUnit 5

## 📋 Функциональность
- Полный цикл управления задачами (CRUD)
- Валидация входных данных
- Поиск задач по id
- Автоматическое ведение истории просмотра задач
- Поддержка двух типов хранения: в оперативной памяти и в CSV файле


## ⚙️ Технологический стек
**Основной стек:**
- **Язык:** Java 21
- **Архитектура:** Чистая Java
- **Веб-сервер:** Встроенный `com.sun.net.httpserver.HttpServer`
- **Сборка:** IntelliJ IDEA
- **Тестирование:** JUnit 5

**Хранение данных:**
- **In-Memory:** Для работы в оперативной памяти
- **CSV-файлы:** Для постоянного хранения состояния

## 🏗️ Архитектура и ключевые компоненты

### Модель данных
Система работает с тремя типами задач:

| Тип                     | Описание                                                                                                                                                                                                                                                                                 |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Задача (Task)**       | Базовая единица работы. Имеет название, описание, статус (`NEW`, `IN_PROGRESS`, `DONE`), дату начала, время на выполнение. Задачи не могут пересекаться по времени.                                                                                                                      |
| **Эпик (Epic)**         | Крупная составная задача. Содержит список подзадач. Его итоговый статус автоматически рассчитывается на основе статусов всех его подзадач. Дата начала - дата начала самой ранней подзадачи, дата конца - дата самой поздней подзадачи, длительность - сумма длительностей всех подзадач |
| **Подзадача (Subtask)** | Конкретный шаг в рамках Эпика. Всегда привязана к родительскому Эпику.                                                                                                                                                                                                                   |

### Сервисный слой
Реализованы два менеджера задач с единым интерфейсом:
1. **`InMemoryTaskManager`** - Хранит все данные в оперативной памяти (`HashMap`).
2. **`FileBackedTaskManager`** - Сохраняет состояние задач в CSV-файл и восстанавливает его при запуске.

### История просмотров
* **`InMemoryHistoryManager`**: отслеживает историю последних просмотренных задач.
* Реализован на двусвязном списке для эффективного добавления и удаления.
* Исключает дублирование: повторный просмотр той же задачи перемещает её в конец списка.
